# gita sloka

A full-screen Bhagavad Gita face: read a verse in Sanskrit, transliteration, English and Hindi, with chapter and verse jump, a daily verse, favorites and a reading view.

Verses come from the public vedicscriptures API. The optional reflection button asks the OpenCode CLI (and the model it is set up with) for a short commentary, without letting it use tools, and caches the answer on the device. Favorites, language, chapter, verse and reflection settings stay on the device; nothing personal is sent anywhere.
